### Desarrollo 
1)	Repositorio: GITHUB

Para la construcción de mi portafolio digital, seleccioné GitHub como repositorio principal. Esta elección se basa en varias características que lo hacen especialmente adecuado para un perfil de una recién egresada que se integra al mundo del desarrollo de software.
En primer lugar, GitHub centraliza en un mismo lugar tanto el código fuente de los proyectos como su presentación pública, a través de un perfil con biografía, repositorios destacados y un README personal. Esto permite que cualquier persona interesada (reclutador, equipo técnico, u otro profesional) no solo vea una descripción de mis proyectos, sino que pueda revisar directamente cómo fueron implementados.
Además, GitHub ofrece GitHub Pages, un servicio de hosting gratuito que permite publicar sitios web estáticos directamente desde un repositorio, sin necesidad de contratar un servidor externo, lo que es ideal para alojar tanto el portafolio en sí como proyectos de frontend desarrollados durante la carrera que desarrolle, todo en un mismo lugar.
En comparación con otras alternativas, como Heroku, que está orientada principalmente al despliegue de aplicaciones backend en producción y cumple una función más robusta que la de un portafolio personal, Stack Overflow es una plataforma de preguntas y respuestas técnicas que permite demostrar participación en la comunidad, pero no está diseñada para alojar proyectos. Por su parte, YouTube es útil para compartir contenido audiovisual, como demostraciones en video, pero no permite gestionar ni versionar código. GitHub, en cambio, reúne en una sola plataforma el control de versiones, el alojamiento de proyectos y la visibilidad profesional, por lo que considero que es la alternativa más adecuada para desarrollar este portafolio. Además, es una de las plataformas más utilizadas para este propósito y fue una de las herramientas que aprendimos a utilizar durante el bootcamp.

3)	Selecciona 1 de las últimas 3 pruebas realizadas en el bootcamp y justifica tu elección. Considera anexar la prueba a través de un vínculo de visualización.

Link: https://github.com/Pamela-Veloso/proyecto-Arriendo-Inmuebles

Para este requerimiento, seleccioné el proyecto "Arriendo de Inmuebles", desarrollado en Django con PostgreSQL, como evidencia de mis habilidades en desarrollo backend. Esta elección se justifica en tres aspectos:
Primero porque es el trabajo más reciente y completo que he desarrollado durante el curso, construido de forma incremental a lo largo de cinco hitos: 1) configuración del entorno y conexión a base de datos, 2) configuración del panel de administración y autenticación de usuarios, 3) migraciones y recuperación de datos mediante el ORM y SQL, 4) desarrollo de una aplicación con el patrón MVC (MTV), y 5) finalmente operaciones CRUD completas utilizando el ORM de Django.
En segundo lugar, el proyecto demuestra un rango amplio de habilidades técnicas, como son el modelado de datos relacional con llaves foráneas, autenticación y gestión de permisos y grupos de usuarios (Arrendatarios y Arrendadores con distintos niveles de acceso), consultas SQL con JOIN para generación de reportes, y la implementación completa de un flujo CRUD (crear, leer, actualizar y eliminar) protegido por reglas de seguridad que garantizan que cada usuario solo pueda gestionar sus propios datos.
Por último, aunque no recibí retroalimentación formal de un docente sobre este proyecto en particular, apliqué de forma autónoma varias mejoras durante su desarrollo que considero relevantes para destacar como evidencia de criterio profesional:
•	Validaciones de datos a nivel de modelo, para evitar valores inconsistentes como superficies o precios negativos.
•	Rediseño de la interfaz utilizando Bootstrap, mejorando la usabilidad de una versión inicial funcional pero visualmente básica.
•	Implementación de selectores dependientes (región → comuna) mediante JavaScript, para evitar combinaciones de datos geográficos inválidas.
•	Verificación de propiedad de los datos en las vistas de edición y borrado, impidiendo que un usuario pueda modificar inmuebles que no le pertenecen.
Estas decisiones no solo permitieron cumplir con los requerimientos técnicos de cada hito, sino que también demostraron la capacidad de identificar y resolver por iniciativa propia problemas de usabilidad y seguridad. Esto contribuyó a desarrollar una aplicación más funcional, segura y adaptada a las necesidades reales de los usuarios.
